# Integrated-FP-A-Analysis-
CoPilot Assisted financial analysis of budget-vs-actual metrics and performance

Project Overview
An end-to-end Financial Planning & Analysis (FP&A) project analyzing H1 budget-versus-actual performance, evaluating driver variances, building an H2 scenario-driven financial forecast, and utilizing Microsoft 365 Copilot with human-in-the-loop verification.

## Core Technical Skills Demonstrated
* **Financial Modeling & Variance Analysis:** Budget vs. Actual reconciliation, operating margin tracking, and H2 scenario modeling (Base, Upside, Downside).
* **Excel Engineering:** Dynamic formulas, weighted margin calculations, dynamic scenario projections, and executive dashboards.
* **AI-Assisted Workflow & Auditability:** Leveraging Copilot for initial review while performing manual formula auditing and reconciliation.

## Key Insights
* **H1 Performance:** Operating income missed budget by $105k (-10.0%), primarily driven by June revenue contraction (-$30k) and expense overruns (+$25k).
* **H2 Forecast Range:** H2 operating income projected between $793k (Downside) and $1.22M (Upside), with a Base Case outcome of $1.03M (28.0% margin).
